# DocuLink: Word ↔ PDF Dönüştürücü

Bu uygulama, Word belgelerinizi PDF'e veya PDF dosyalarınızı Word (.docx) formatına dönüştürmenizi sağlayan kullanımı kolay bir araçtır.

## ✨ Özellikler
* **Word'den PDF'e:** LibreOffice altyapısını kullanarak hızlı dönüşüm sağlar.
* **PDF'den Word'e:** `pdf2docx` kütüphanesi ile belgelerinizin düzenini koruyarak dönüştürür.
* **Toplu İşlem:** Birden fazla dosyayı aynı anda listeye ekleyip dönüştürebilirsiniz.
* **Modern Arayüz:** Sade ve anlaşılır kullanıcı arayüzü.
